# Java Utility Classes & Helpers

Utility class implementations and formatting helpers in Java (`java.time`, `java.lang.Math`, `String`).

## Files

- **`dateAndtimeformatter.java`**: Formatting and parsing dates/times using `LocalDate`, `LocalTime`, and `DateTimeFormatter`.
- **`timeformateer.java`**: Time string formatting techniques.
- **`calendarFormatter.java`**: Date manipulations with legacy `Calendar` / `Date` classes.
- **`mathutilityClass.java`**: Mathematical calculations (`Math.pow`, `Math.sqrt`, `Math.max`, `Math.random`).
- **`stringutilityClass.java`**: String manipulation helper methods (`substring`, `trim`, `split`, `replace`, case conversions).

## How to Run

```bash
javac dateAndtimeformatter.java
java Main

javac stringutilityClass.java
java Main
```

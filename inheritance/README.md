# Inheritance in Java

Examples illustrating Object-Oriented Inheritance patterns in Java.

## Files

- **`hierarchicalInheritance.java`**: One parent superclass extended by multiple child subclasses.
- **`multipleInheritance.java`**: Achieving multiple inheritance in Java using Interfaces (since Java does not support multiple class inheritance directly).

## Key Concepts

- **`extends`**: Used for class inheritance (single, multilevel, hierarchical).
- **`implements`**: Used to inherit contract behaviors from multiple interfaces.
- **`super`**: Used to call parent class constructors or methods.

## How to Run

```bash
javac hierarchicalInheritance.java
java Main

javac multipleInheritance.java
java Main
```

# Java Collections Framework

A collection of programs and exercises covering data structures in Java's Collection API (`java.util.*`).

## Subdirectories

- **`HASHSET/`**: `HashSet`, `LinkedHashSet`, and `TreeSet` set implementations.
- **`LIST/`**: `List` interface methods and `ArrayList` practice problems.
  - **`LIST/LinkedList/`**: `LinkedList` implementation and methods.
- **`MAP/`**: `Map` interface and `HashMap` operations.
- **`QUEUE/`**: `Queue` interface and FIFO operations.
  - **`QUEUE/DEQUE/`**: `Deque` (Double-ended Queue) and `ArrayDeque` usage.
- **`SET/`**: `Set` interfaces, `TreeSet`, `Comparable` & `Comparator` custom sorting, and multi-level sorting.

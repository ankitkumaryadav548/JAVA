# Java List & ArrayList

Examples covering the `List` interface and `ArrayList` operations in Java.

## Files

- **`list.java`**: Basic `List` interface initialization and element insertion.
- **`arrayListMethod.java`**: Methods of `ArrayList` (`add`, `get`, `set`, `remove`, `contains`, `indexOf`, `clear`).
- **`questionOnArrayList.java`**: Practical exercises manipulating dynamic array elements.
- **`anotherquestion.java`**: Additional array list operations and algorithm problems.

## Subdirectory

- **`LinkedList/`**: `LinkedList` implementation and node-based list operations.

## How to Run

```bash
javac arrayListMethod.java
java Main
```

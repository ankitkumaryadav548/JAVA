# HashSet & Set Implementations

Demonstrates unique element storage and operations using `HashSet`, `LinkedHashSet`, and `TreeSet`.

## Files

- **`set.java`**: Basic `HashSet` creation, duplicate prevention, and element deletion.
- **`LinkedHashSet.java`**: `LinkedHashSet` usage, preserving insertion order while maintaining unique elements.
- **`treeSet.java`**: `TreeSet` usage for naturally ordered, sorted set storage.
- **`Map.java`**: Set-based map key/entry set examples.

## Key Takeaways

| Class | Duplicates Allowed | Order Preserved | Sorted |
|---|---|---|---|
| `HashSet` | No | No | No |
| `LinkedHashSet` | No | Insertion Order | No |
| `TreeSet` | No | Sorted Order | Yes |

## How to Run

```bash
javac set.java
java Main
```

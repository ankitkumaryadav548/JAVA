# Java Input & Output (I/O)

Code examples covering console I/O, stream reading, and input parsing in Java.

## Files

- **`inputOutputInJava.java`**: Interactive console input loop reading lines with `Scanner` until an "exit" command is given.
- **`exOnIO.java`**: Reading and printing formatted user inputs.
- **`O.java`**: Console output formatting techniques.
- **`thread.java`**: I/O operations combined with thread processing.

## How to Run

```bash
javac inputOutputInJava.java
java Main
```
